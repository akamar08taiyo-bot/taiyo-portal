# 介護施設 売上マップ（福岡県）

福岡県内の介護施設の売上を、施設ごとに地図上へプロットして把握するための単一HTMLアプリです。
CSVを取り込むと、同じ施設の行を自動で合算し、市区町村の代表地点付近にマーカーとして表示します。

以前 Codex で作成・Netlify にCLIから直接デプロイされていたバージョンとは別に、
このリポジトリでコードを新規に作成しました（元のデプロイはGitHubと連携しておらず、
ソースを回収できなかったため）。

## 使い方

1. `index.html` をブラウザで直接開く（ビルド済みの単一ファイルなので、ローカルで開くだけで動作します）
2. 営業所を選択
3. 「CSV取り込み」から、次の列を持つCSVを読み込む
   - `施設名` / `自治体`（福岡県内の市区町村。政令市は「福岡市博多区」のように区まで指定）/ `担当者` / `売上`
   - 同じ施設名＋自治体の行は自動で合算されます
   - 「サンプルCSV」ボタンでテンプレートをダウンロードできます

## 開発

このアプリは React（JSX）を単一HTMLに事前バンドルする構成で、`index.html`（リポジトリ直下）が
そのビルド成果物です。ソースは `src/index.html` と `src/lib/*.mjs` にあります。

```bash
cd build
npm install
npm run build   # ../index.html を再生成
```

ロジックのテスト（CSVパース・自治体名解決・集計）:

```bash
npm test
```

### ディレクトリ構成

- `src/index.html` — Reactアプリ本体（JSX）
- `src/lib/municipalities.mjs` — 福岡県60自治体（政令市は区単位、計72地点）の概算座標と名寄せ
- `src/lib/csv.mjs` — CSVパース・エンコーディング判定・集計ロジック
- `src/lib/jitter.mjs` — 同一自治体内の施設をマーカー上で見分けるための決定的オフセット
- `build/` — esbuild + Tailwind CSS のビルドスクリプト（外部CDN不要の単一HTMLを生成）
- `test/` — `src/lib` のロジックに対する Node テスト

### 地図データについて

施設の座標は、市区町村の代表地点（概算）に施設名から決定的に求めた小さなオフセットを
加えたものです。番地レベルの正確な位置ではなく、あくまで「どのエリアにどの程度の売上があるか」を
俯瞰するための表示です。
